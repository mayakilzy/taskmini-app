# TaskMini

مدير مهام بسيط مع فلترة حسب الأولوية، وضع داكن، واستمرارية في LocalStorage.

## الميزات

- إضافة مهام بعنوان وأولوية (منخفضة، متوسطة، عالية)
- تحديد المهام كمنتهية
- حذف المهام
- فلترة المهام حسب الأولوية
- دعم الوضع الداكن
- استمرارية في LocalStorage

## البدء

1. قم بتثبيت الاعتماديات:
   bash
   npm install
   

2. تشغيل خادم التطوير:
   bash
   npm run dev
   

3. افتح [http://localhost:3000](http://localhost:3000) في متصفحك.

## الاستخدام

- إضافة مهام جديدة باستخدام حقل الإدخال ومحدد الأولوية
- انقر على المربع لتعيين المهام كمنتهية
- انقر على أيقونة المهلات لحذف المهام
- استخدم أزرار الفلترة لعرض المهام حسب الأولوية
- قم بالتبديل إلى الوضع الداكن باستخدام الزر في الزاوية العلوية اليمنى

مهامك يتم حفظها تلقائيًا في LocalStorage وتستمر بين جلسات العمل.
