# TaskMini

A simple task manager with priority filtering, dark mode, and localStorage persistence.

## Features

- Add tasks with title and priority (low, medium, high)
- Mark tasks as complete
- Delete tasks
- Filter tasks by priority
- Dark mode support
- LocalStorage persistence

## Getting Started

1. Install dependencies:
   bash
   npm install
   

2. Run the development server:
   bash
   npm run dev
   

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Usage

- Add new tasks using the input field and priority selector
- Click on the checkbox to mark tasks as complete
- Click the trash icon to delete tasks
- Use the filter buttons to view tasks by priority
- Toggle dark mode using the button in the top right corner

Your tasks are automatically saved to localStorage and will persist between sessions.
